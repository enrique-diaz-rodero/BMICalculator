# 🏋️‍♂️ PulseFit IMC - Calculadora de Índice de Masa Corporal

Bienvenido al repositorio de **PulseFit IMC**, una aplicación diseñada para calcular el Índice de Masa Corporal (IMC) de forma rápida, precisa y visual. El objetivo de este proyecto es ayudar a los usuarios a conocer su estado de salud a partir de su peso y altura, promoviendo hábitos saludables.

> *"¡Construye tu mejor versión! Mide tu índice y regula tu salud cada día."*

## 📌 Características del Proyecto

Este repositorio está estructurado en **dos ramas principales**, cada una con un propósito específico para demostrar la evolución del desarrollo:

### 1. Rama `main` (App Básica)
*   **Enfoque:** Lógica y funcionalidad pura.
*   **Descripción:** En esta rama se encuentra la aplicación básica. Carece de estilos visuales avanzados, colores o diseño de interfaz de usuario (UI). Su único propósito es recibir los datos (peso y altura) y realizar el cálculo matemático del IMC de forma funcional.

### 2. Rama `UI_Main` (App con Estilo)
*   **Enfoque:** Experiencia de Usuario (UX) y Diseño de Interfaz (UI).
*   **Descripción:** En esta rama se encuentra la versión final y editada de la aplicación. Incluye un diseño moderno, intuitivo y atractivo visualmente. Cuenta con una paleta de colores corporativa, controles interactivos (botones de ajuste rápido y sliders) y una presentación clara de los resultados.

## ✨ Funcionalidades Principales (Rama UI_Main)

*   **Personalización:** Campo de entrada para el nombre del usuario ("¿Cómo te llamas, atleta?").
*   **Control de Peso:** Botones de ajuste rápido (`-5 kg`, `-1 kg`, `+1 kg`, `+5 kg`) para modificar el peso actual.
*   **Control de Altura:** Deslizador (Slider) interactivo para ajustar la altura en centímetros.
*   **Cálculo Automatizado:** Botón principal de acción para calcular el IMC ("¡Calcular IMC de [Nombre]!").
*   **Resultados Visuales:** Presentación destacada del resultado del IMC con códigos de color (ej. rojo para niveles altos) para una interpretación rápida.
